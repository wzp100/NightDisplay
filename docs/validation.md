- 原生守护 CMake Release 与 Debug 配置均成功构建。

集成检查覆盖显示 ABI、恢复序列化、默认关闭网页、共享心跳与协议 v2、状态事件、UTF-8 固定资源、授权与来源、分片 HTTP、正文预读、限流、大小限制和不完整请求超时。集成检查不实际切换显示器。

| 检查 | 结果 |
| --- | --- |
| 默认后台启动 | 无设置进程、无 HTTP 监听端口 |

## 最终资源采样

实体输出、网页关闭、设置进程不存在，15 秒空闲采样。两个进程为最终部署的 1.2 构建。

| 指标 | 控制后台 | 原生守护 | 合计 |
| --- | ---: | ---: | ---: |
| 工作集 MiB | 37.73 | 3.64 | 41.37 |
| 私有提交 MiB（Private Bytes） | 24.78 | 0.58 | 25.36 |
| CPU 时间增量，秒 | 0.0000 | 0.0000 | 0.0000 |
| Read/WriteOperations 增量 | 0 / 0 | 0 / 0 | 0 / 0 |
| 句柄数 | 345 | 42 | 387 |

守护文件为 5120 字节，文件大小与进程工作集不同。设置窗口关闭后其进程完全退出，不保留控件、字体、图片或设置刷新计时器；控制后台仍使用 CLR 与基础窗口消息框架，不能声称总后台 UI 框架成本为零。

上一版后台样本合计工作集 78.41 MiB，本版 41.37 MiB，约减少 47.2%；私有提交从 49.81 降至 25.36 MiB。旧样本与新样本运行历史及网页开关不同，不能将比例视为稳定性能承诺。工作集包含共享系统代码，进程求和可能重复计算共享页；Private Bytes 也不等于当前物理私有内存。

15 秒没有可测 CPU 时间增长或读写操作不代表永远零开销。切换、虚拟状态检查、故障、日志、界面或网页开启仍消耗资源。网页关闭会释放服务与连接；CLR 可以保留已经加载过的模块/缓存，工作集不保证立即回到首次启动值。应用不控制风扇噪声。
